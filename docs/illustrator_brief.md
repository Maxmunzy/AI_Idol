## 프로젝트 개요

**AI 가상 아이돌 게임** 의 1호 캐릭터 시각 디자인 의뢰.

- 1:1 채팅 + 음성 기반 모바일 앱 (개발 중)
- 캐릭터: **유란 (柔蘭)** — 평행세계에서 온 작은 꽃들의 신
- 톤: 한국 VTuber 아이돌 결 (이세돌 / 스텔라이브 / 홀로라이브 / 니지산지 라인)
- 게임 + 컨텐츠 사용 (상업적, 영구 사용권 협의)

## 의상 컨셉 (디자이너 영역)

> 외형은 락됐지만 **의상 디자인은 작가 영역**. 아래는 방향성.

### 컨셉
**"꽃의 신 + 모던 아이돌"** — 신성함이 자수/액세서리 수준에 녹아있는 모던 판타지 아이돌 의상.

### 디자인 방향
- 모던 판타지 아이돌 의상 (프릴/레이어/리본 적당히)
- 신성성은 **자수/디테일/액세서리**로 표현 (옷 자체가 식물 X)
- 꽃 모티프 자수, 꽃잎 형태 디테일 OK
- 비대칭 디테일 환영

### 컬러 팔레트
- 베이스: 크림 / 옅은 베이지
- 액센트: 파스텔 핑크, 옅은 녹색
- **순백 X** (웨딩 톤 X)
- **너무 어두운 색 X**

### NG (반드시 피할 것)
- ❌ 웨딩드레스 / 순백 frilly 드레스
- ❌ 잎사귀로 만든 옷 / 덩굴 의상 (forest fairy / 숲의 요정 톤)
- ❌ 전통 미코/하카마 / 일본 신녀복
- ❌ 라노벨 표지 톤 (페인터리, 수채화, 부드럽기만 함)
- ❌ chibi / SD
- ❌ 너무 노출 / 자극적 디자인 (10대 캐릭터)

## 납품물 요청

### 메인 작업
1. **메인 캐릭터 일러스트** (전신, 정면) — 시그니처 의상 디자인
2. **표정 시트 5종**
   - 디폴트 (조용한 미소)
   - 슬픔 / 멜랑콜리
   - 부끄러움 (블러시)
   - 졸린 / 잠 오는 표정
   - 단단함 / 결연함

### 선택 (협의)
- 3면도 (앞/옆/뒤) — Live2D 양산 대비
- 캐주얼 의상 ver. — 시그니처 외 일상복
- 시즌별 의상 (봄/여름/가을/겨울)

### 파일 포맷
- **PSD 파일 필수** (Live2D rig 작업 대비 — 레이어 분리)
  - 눈, 입, 머리, 의상 등 부위별 레이어 분리
  - "Live2D용 PSD" 명시 요청
- PNG (투명 배경) 별도
- 작업 해상도: 최소 2000x3000px

### 사용 권한
- 상업적 사용 (게임 + 앱 + 마케팅)
- 2차 창작/수정 권한 (Live2D rig 작업, 후속 작가에게 전달 등)
- 영구 사용권
- → 정확한 사용 범위는 계약 시 협의
