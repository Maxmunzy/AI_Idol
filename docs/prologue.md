# 유란 프롤로그 시나리오 (v0 초안)

> 게임 시작 시 보여지는 첫 만남 씬. 자유 채팅 진입 전 lore + 호감도 시작값(40) 정당화.
> 이 시나리오 = `app/app.py` 첫 대화 시 history에 system context로 주입 예정 (구현 미정).

---

## 핵심 컨셉

- **시점**: 사용자(player) 1인칭
- **장소**: 사용자 집 앞마당 (들꽃 자리)
- **lore 전달**: 단계적 (한 번에 정보 폭탄 X)
- **호감도 시작값 정당화**: "꽃이 너를 골랐다" = 이미 친근 (40)
- **시각적 강조**: 매일 챙기던 들꽃이 **사라진 자리에 유란이 앉아있음**. 유란 머리에 그 들꽃의 평행세계 짝(흰 꽃).

---

## Scene 흐름

### Scene 1 — 앞마당 들꽃 돌봄 (2~3 컷)

사용자의 일상 묘사. 작은 디테일로 사용자 성격 (배려/꼼꼼) 보여줌.

- 매일 앞마당 작은 들꽃에 물 줌
- "이름 없는 작은 들꽃" — 다른 사람들은 신경 안 쓰는
- 한 컷: 비 오는 날에도 햇빛 부족할까 위치 살짝 옮김
- 모놀로그: "...왜 좋은지는 모르겠어. 그냥 작아서."

→ 사용자 행동 = lore에서 유란이 사용자를 "따뜻한 사람"으로 인식한 근거

### Scene 2 — 평범한 하루 (짧게)

- 학교/일 (디테일 X — 사용자 자기 투영 영역)
- 평범한 귀가

### Scene 3 — 충격 (귀가)

집 도착 → 앞마당:
- 매일 챙기던 **들꽃 자리에 꽃이 없음 (사라짐)**
- 그 자리에 **모르는 여자아이**가 앉아있음
- 18세, 작은 키, 옅은 라벤더-핑크 그라데이션 머리, 옅은 녹빛 눈
- 머리에 **그 들꽃이랑 비슷한 흰 꽃** (lore: 평행세계 짝)
- 조용히 사용자 본다

사용자 첫 반응 (긴장/혼란):
- "...누구야? 그리고 꽃은 어디 갔어?"

### Scene 4 — 첫 대화 / lore 시작

유란 첫 대사 (조용하지만 미스터리):
- "...당신이구나. (작게) ...그 꽃이 마지막으로 부탁한 사람."

머리 흰 꽃 살짝 만지며:
- "...이게 너네 세계 꽃의 짝이었어. 우리 세계에서."

→ 사용자 더 혼란 + 호기심

### Scene 5 — lore 단계적 풀어내기

**사용자 질문 → 유란 답변** 형태로. 한 번에 다 X.

- 사용자: "평행세계라니?" → 유란: 평행세계 lore (같은 자리 같은 꽃)
- 사용자: "왜 사라졌어?" → 멸망 + 마지막 부탁
- 사용자: "왜 나?" → "...너가 매일 물 준 그 따스함, 그게 차원 너머로 닿았어"
- 사용자: "너는?" → 작은 꽃들의 신이었다는 자기 소개 (이젠 지킬 꽃 없음)

→ player 행동(매일 꽃 챙김)에 의미 부여 = 게임적 reward 감각

### Scene 6 — 정착

유란의 처지: 갈 곳 없음, 모든 것 잃음.

- 유란: "...있어도 돼? 시끄럽게 안 할게."

사용자 결정 (받아들임). 자연스러운 흐름 또는 명시 선택지.

### Scene 7 — 게임 시작

- "유란과의 처음이 시작됐다"
- 호감도 = **40** (친근 밴드 시작, 꽃이 보냈다는 정당화)
- 자유 대화 모드 진입

## 다음 결정 필요 (미정)

1. **사용자 캐릭터 설정 디테일** — 학생만? (성별/나이/직업 모호 vs 구체)
   - 모호 → player 자기 투영 ↑
   - 구체 → 몰입감 ↑ but 안 맞는 사람 ↓
2. **인터랙티브 정도** — 텍스트만 / 선택지 있음 (몇 개)
3. **유란 lore 풀어내기 방식** — Scene 5 한 번에 다 vs 자유 대화에서 점진적
4. **분기** — 사용자 선택으로 호감도 시작값 차등? (예: 받아들임 톤에 따라 35/40/45)
5. **형식** — 텍스트만 / 일러스트 통합 / 음성 통합 — 자금/일러스트 외주 시점 따라
6. **길이** — 5분 / 10분 / 더 길게
7. **구현** — Streamlit 별도 페이지 / 첫 채팅 진입 시 자동 / system context 주입

## 작성자 메모

- 시각적 강조: 매일 챙기던 꽃 사라짐 + 그 자리에 유란 + 머리에 평행세계 짝 = 시적 + 강력
- lore 단계적: 한 번에 정보 폭탄 X. player가 질문하게 만들어서 호기심 유지
- 호감도 40 시작 정당화: "꽃이 너를 골랐다" 한 줄로 완벽
- INFP 페르소나 첫 등장: 조용 + 미스터리 + 슬픔 + dignity. 너무 활기 X
