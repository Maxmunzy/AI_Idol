# 유란 프로젝트 로드맵

> 개인 마인드셋용. 본인이 읽으면서 정신 차리는 용도.
> README나 system_design은 외부용. 이건 솔직한 내부 정리.

---

## 전체 horizon — 2~3년

```
[Phase 0] 지금: KDT + 백수 → 취업
[Phase 1] 취업 직후: 자금 모음
[Phase 2] 데모 v1 빌드 (일러스트 통합)
[Phase 3] 베타 검증 (PMF 신호 확인)
[Phase 4] 모바일 + 본격 launch
[Phase 5] 운영 + 확장
```

---

## Phase 0 — 지금 (KDT 중, 백수, 자금 0)

**기간**: 3~6개월 (KDT 수료 + 취업 활동)

**제약**: 시간 있음 (단 KDT 우선), 돈 0

**목표**: **취업** + 포트폴리오 완성도 ↑. 사업이 아니라 포트폴리오 모드.

**할 일** (자금 무관, 시간으로 가능):
- `core/` 리팩토링 + 게임 엔진 구현 (작동하는 데모까지)
- 위험 가정 prototype (호감도 LLM 판정 / 씬 진행)
- 프롤로그 + 스타터 이벤트 스토리
- 블로그 글 1편 (취업 어필 + 미래 검색 노출)
- 이력서/포트폴리오 사이트
- KDT 수료, 취업 활동

**Exit**: 취업 + 첫 월급

---

## Phase 1 — 취업 직후 (자금 모음)

**기간**: 3~6개월

**제약**: 시간 줄어듦 (퇴근 후만), 돈 매월 들어옴

**목표**: 일러스트 외주 자금 마련

**할 일**:
- 매월 일정 저축 (예: 10~20만원 → 6개월 60~120만원)
- 일러스트레이터 후보 풀 빌드 (트위터/크몽 패시브)
- 시간 날 때 게임 엔진 안정화

**Exit**: 외주 자금 확보 + 작가 컨택 준비

---

## Phase 2 — 데모 v1 빌드

**기간**: 3~4개월

**제약**: 시간 = 퇴근 후, 돈 = 일러스트 50~150만원 + AI 크레딧

**목표**: 일러스트 통합된 작동 데모

**할 일**:
- 일러스트레이터 외주 (시그니처 의상 + 표정 5종 + Live2D용 PSD)
- AI 이벤트 일러스트 생성 (NAI Vibe Transfer)
- 게임 엔진 + 일러스트 통합
- 프롤로그 + 5~10 스타터 이벤트 완성

**Exit**: 데모 v1 완성, 본인 1차 검수 OK

---

## Phase 3 — 베타 검증 ★ 분기점

**기간**: 1~3개월

**제약**: 호스팅 + API 비용 (월 몇만원)

**목표**: PMF 신호 — 사람들이 다시 오나? 돈 낼 의향 있나?

**할 일**:
- Streamlit Cloud 또는 간단 호스팅
- 디시 버튜버 갤러리 / 트위터 익명 베타 모집
- 5명 → 20명 → 50명 단계적
- 피드백 수집, 시스템 튜닝
- 사용 데이터 누적 (호감도 판정 데이터 = 나중 파인튜닝용)

**Exit (진실의 순간)**:
- ✅ PMF 신호 명확 → Phase 4 진입
- ⚠️ 모호함 → 조정 + 재테스트
- ❌ 신호 없음 → 피벗 또는 종료

---

## Phase 4 — 모바일 + 본격 launch

**조건**: Phase 3에서 PMF 신호 (없으면 안 들어감)

**기간**: 6개월 ~ 1년

**제약**: 가능하면 사이드 → 풀타임 전환 검토, 돈 200~500만원

**할 일**:
- `core/` → FastAPI 백엔드 래핑
- Flutter/RN 학습 + 모바일 앱 빌드
- Live2D 외주 (메인 일러스트 → rig 작업)
- 양방향 음성 (STT 추가)
- FCM 푸시 ("유란이 기다려")
- 구독/결제 모듈
- 앱스토어 출시

**Exit**: 출시 + 첫 결제 사용자

---

## Phase 5 — 운영 + 확장

**조건**: 출시 후 운영

**할 일**:
- 콘텐츠 파이프라인 (월 1~2 시그니처 + 시즌 + 절차적)
- 호감도 판정 v2 (KoBERT 파인튜닝) 전환
- 2호 멤버 페르소나 (모닝구무스메식 영입 사이클)
- 커뮤니티 관리
- 마케팅 본격화

## 마인드셋 reminders (정기적으로 읽기)

### 우선순위 (지금)

1. **KDT 수료**
2. **취업** (= Phase 0 종료)
3. **이 프로젝트 = 포트폴리오 완성도**
4. (월급 시작) → 그 다음에 사업 모자 다시

지금 사업 모드로 가면 burnout만 옴. 취업 우선.

### 시간이 돈을 보상한다

자금 없을 때 = 시간 있을 때 = **설계/IP 구축의 황금기**.

설계 잘 잡으면:
- 일러스트레이터 brief 한 방에 정확
- 개발 외주 시 시간/비용 절감
- 자금 들어와도 어디 쓸지 헤매지 않음

설계 안 잡혔으면 자금 들어와도 시행착오로 다 날림.

### 타임라인은 항상 지연됨

2~3년이 실제론 3~4년 될 가능성 큼. 정상.
- 취업 잘 안 되면 Phase 0 늘어남
- 본인 burnout / 인생 변화 변수
- 시장 변화 (character.ai 같은 거대 플레이어가 시장 먹을 수도)

### 망해도 안 망함 (안전망)

Phase 3에서 PMF 안 나오면 사업으로는 끝.
근데 Phase 0 결과물 (포트폴리오)은 남음. **취업 자산으로 영구 사용 가능**.

이게 이 전략의 본질 — 사업이 안 되어도 망하지 않게 설계됨.

### 위험 가정 검증 잊지 말기

설계 lock 전 핵심 2개 prototype 필수:
1. 감독 LLM 호감도 판정 자연스러운가
2. 자유 입력 씬 진행 매끄러운가

설계만 무한히 다듬으면 함정. 코드로 찔러봐야 진짜 안다.

### 외부 평가는 Phase 3에 받기

지금 데모 뿌리면 비주얼 부족해서 묻힘.
일러스트 + 스토리 완성 = Phase 2 끝난 후 = Phase 3에서 검증.

그 전에 친구한테 보여주는 거 = 잘못된 검증 대상 (타겟 demo가 아님).

### 마지막

본인이 솔로로 3일 만에 캐릭터 + 음성 + DB + 게임 설계까지 온 거 = 페이스 좋음.
조급해하지 말고, 2~3년 horizon으로 보면서, 컨디션 좋을 때 한 걸음씩.

망상은 즐겁게, 실행은 꾸준하게.
